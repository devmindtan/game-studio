# addons/gamekit (bản sao, không sửa ở đây)

Thư mục này do `gamekit install` chép từ `tools/gamekit/addon/gamekit/` của workspace, và lần cài sau sẽ ghi đè.
Muốn sửa: sửa ở `tools/gamekit/addon/gamekit/`, tăng `tools/gamekit/VERSION`, rồi chạy `gamekit install <game>`.

- `lpc/`: `LpcCharacter` (có trong bản export), bố cục LPC, builder SpriteFrames
- `debug/`: màn xem nhân vật (không vào bản export)
- `test/`: bộ chạy test headless (không vào bản export)
